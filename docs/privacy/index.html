개인정보처리방침

NELplayer 안드로이드 앱 · 만든 곳 NEL Studio · 시행일 2026년 10월 18일

NELplayer(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다.

1. 수집하는 정보

앱은 이름, 이메일, 기기 식별자, 위치, 연락처 같은 개인정보를 수집하거나 서버로 보내지 않습니다. 광고나 분석 도구를 쓰지 않고, 계정도 없습니다.

2. 기기 안에만 저장하는 정보

다음 정보는 사용자의 기기 안(앱 전용 저장 공간)에만 저장되며 밖으로 보내지 않습니다. 앱을 지우면 함께 지워집니다.

  • 사용자가 연결한 폴더의 위치와 접근 권한
  • 화별 시청 위치(이어보기)와 다 본 표시
  • 앱 설정(화면 표시, 두 번 탭 이동 시간 등)

사용자가 만든 클립과 화면 캡처는 사용자가 볼 수 있도록 기기의 동영상·사진 › NELplayer 폴더에 저장됩니다.

3. 영상·자막 파일 접근

앱은 사용자가 직접 고른 폴더(안드로이드 저장소 접근 프레임워크)의 영상·자막·글꼴 파일만 읽습니다. 파일 내용을 밖으로 보내지 않습니다.

4. 인터넷 사용

앱은 사용자가 "자막 글꼴 받기"를 누를 때만 인터넷을 씁니다. 이때 GitHub(github.com, GitHub, Inc.)의 공개 저장소 Nelsuss/NELplayer-fonts에서 글꼴 파일을 받습니다. 이 과정에서 GitHub가 일반적인 웹 요청 정보(IP 주소 등)를 처리할 수 있으며, 이는 GitHub 개인정보처리방침을 따릅니다.

5. 문제 해결용 재생 기록

설정에서 "문제 해결용 재생 기록 남기기"를 켠 경우에만 재생 기록 파일을 기기의 앱 전용 폴더에 남깁니다. 이 파일은 자동으로 보내지지 않습니다.

6. 아동의 개인정보

앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.
