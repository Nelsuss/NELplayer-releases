# NELplayer 배포

애니메이션에 특화된 Windows 동영상 플레이어 **NELplayer** 의 설치 파일을 올리는 곳이에요.

- 최신 설치 파일: [Releases](https://github.com/Nelsuss/NELplayer-releases/releases/latest) 에서 `NELplayer-Setup-<버전>.exe` 를 받아 실행하세요.
- 설치된 앱은 여기에 올라온 새 버전을 스스로 확인하고 업데이트해요 (`latest.json` · `latest.json.sig` 는 앱이 쓰는 서명된 업데이트 정보예요).
- 안드로이드 앱: Releases 의 `android-v<버전>` 에서 `NELplayer-<버전>.apk` 를 받으세요. 앱은 `docs/android/latest.json`(GitHub Pages)으로 새 버전을 알아요.
- 피드백은 블로그에 남겨 주세요: https://blog.naver.com/masanory6853
